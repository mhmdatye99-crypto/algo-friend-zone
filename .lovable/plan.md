
# اعادة هيكلة التطبيق بمستوى CoinMarketCap العالمي

## المشكلة الحالية
التطبيق يعاني من فوضى تنظيمية: الصفحات مزدحمة بأقسام كثيرة متنافسة، شريط التنقل غير واضح، لا يوجد شريط علوي موحد (Top Header)، والتنقل بين الأقسام غير بديهي. النتيجة تجربة مستخدم بعيدة عن مستوى التطبيقات المالية العالمية.

## الخطة الشاملة

### 1. إضافة شريط علوي موحد (Top App Bar)
- شريط ثابت في أعلى كل صفحة يحتوي على: شعار التطبيق (يسار)، شريط أسعار متحرك مصغر (وسط)، وأيقونات الإشعارات + الملف الشخصي (يمين)
- تصميم glassmorphism متناسق مع باقي التطبيق
- ازالة العناوين المكررة من داخل الصفحات واستبدالها بالشريط العلوي

### 2. اعادة هيكلة شريط التنقل السفلي (5 أزرار نظيفة)
- تنظيف الشريط ليصبح بالترتيب:
  1. **الرئيسية** (Home) - الداشبورد
  2. **الأسواق** (Markets) - قائمة الأصول بأسلوب CoinMarketCap
  3. **الشارت** (Chart Vision) - الزر المركزي المميز
  4. **الإشارات** (Signals) - التوصيات
  5. **المزيد** (More) - قائمة تضم: المجتمع، الأكاديمية، الملف الشخصي، الأوديسة المالية، الملخص الصباحي

### 3. اعادة تصميم صفحة الرئيسية (Dashboard)
- **القسم العلوي**: بطاقة ملخص المحفظة (رصيد + نسبة التغيير اليومي) بأسلوب CoinMarketCap
- **شريط الأسعار**: أعلى الأصول المتحركة (Trending) بشكل أنظف
- **نبض السوق**: بطاقة مختصرة (ليست ضخمة) مع مؤشر الخوف/الطمع
- **مسار الثروة**: شريط تقدم مختصر
- **الأصول المفضلة**: قائمة مصغرة
- **ازالة**: أزرار القوة الدائرية، مهام البحث، نبض المجتمع — تنقل لصفحة "المزيد"

### 4. انشاء صفحة "الأسواق" المستقلة (بأسلوب CoinMarketCap)
- نقل قائمة الأصول الكاملة من الداشبورد الى صفحة مستقلة
- تبويبات التصنيف (الكل، كريبتو، فوركس، سلع، مؤشرات) في الأعلى
- شريط بحث مدمج
- جدول أصول احترافي: الترتيب، الأيقونة، الاسم، السعر، التغيير 24h، الشارت المصغر، الحجم
- زر المفضلة والفلترة

### 5. انشاء صفحة "المزيد" (More Menu)
- قائمة منظمة بأيقونات تضم كل الصفحات الثانوية:
  - المجتمع (غرفة العمليات)
  - الأكاديمية الكمية
  - الأوديسة المالية (Goal Planner)
  - الملخص الصباحي
  - الملف الشخصي والإعدادات
  - حاسبة المخاطر
- كل عنصر ببطاقة صغيرة مع أيقونة ووصف مختصر

### 6. تنظيف وتوحيد التصميم عبر كل الصفحات
- padding موحد (px-4 pt-6 pb-28) عبر كل الصفحات
- ازالة عناوين الصفحات الكبيرة المكررة (يتم عرض اسم الصفحة في الشريط العلوي)
- توحيد corner radius (12px للبطاقات، 10px للأزرار)
- التأكد من JetBrains Mono لكل الأرقام
